# 需求说明与合理性备注（v1.9）

## 角色
| 角色 | 能力 |
|------|------|
| admin | 用户/群组/馆可见性/全部书 |
| user | 本可见范围内扫码入库、建本群馆、刮削 |
| viewer | 仅搜索查看可见馆与书 |

无自助注册；用户可改自己的密码。

## 群组与馆可见性
- 群组下可有多馆
- **group**：仅所属群组成员可见（普通用户建馆默认此模式）
- **public**：所有登录用户可见（**仅管理员**可建/改）
- **custom**：管理员指定多个群组可见

管理员可随时改某馆的可见范围。

## 图书
- 拍照/选图 ISBN 入库（主）；手动 ISBN；批量多图
- 同馆 ISBN 去重；刮削书名作者封面（依赖出网）

## 已识别的需求张力（实现取舍）
1. **「群组馆仅本群」vs「管理员指定多群」**  
   → 用 visibility=group|public|custom 统一，不矛盾。
2. **「所有人都能看到」**  
   → 指登录用户，不是匿名；与「必须登录」一致。
3. **user 建馆 vs 跨群分享**  
   → user 只能建本群馆；跨群/全员仅 admin，避免越权。
4. **viewer 与「馆」Tab**  
   → viewer 只保留藏书查看，隐藏扫描/建馆/用户。
5. **刮削不稳定**  
   → 外网/中文源限制；提供单本与批量再刮，非功能矛盾。
6. **实时扫描 vs 拍照**  
   → 拍照更稳；实时扫描可关，避免双路径体验分裂。
